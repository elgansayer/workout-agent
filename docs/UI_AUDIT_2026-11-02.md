# Workout UI audit — 2 November 2026

Source: #1053. Base: `7a5bcd0`. Scope: all eleven Angular routes and their shared navigation. Synthetic API fixtures only; no real health records or credentials are included.

## Verification

- `cd frontend && npm ci --legacy-peer-deps`: deterministic repository install. Plain `npm ci` still encounters the pre-existing Spartan/Tailwind peer mismatch; the established CI command is unchanged.
- `npm test -- --watch=false`: 22 tests passed, including list completeness, search/page resets, dashboard refresh failures, stale explanation responses, preview invalidation, selection persistence, settings edit retention, disconnect routing and IME handling.
- `npm run build`: production build passed.
- `npm run test:a11y-preferences`: 11 routes, six shared checks, three display-preference modes passed. The navigation source check accepts additional attributes while retaining its accessible-name requirement and now verifies the disclosure and focus target.
- `npm run test:ui`: 15 Playwright tests passed at 1440px, 390px and 320px. Each viewport visits all 11 routes at normal and 200% root text size. Tests cover search/pagination, keyboard disclosure, menu Escape, route focus, settings sections, routine selection and preview edits. Screenshots use synthetic fixtures. The desktop dashboard fixture contains 11 exercises and 80 reviews and stays below 1500px total height.
- `python -m compileall -q backend`: passed.
- `python -m pytest -q`: 888 passed, 31 optional skips. The local runtime needed the `socksio` transport extra for its configured proxy. No application dependency or network policy was changed for that environment requirement.
- `python -m ruff check backend/tests/test_web_cache_security.py`: passed. Its password-mask assertion is preserved and updated to recognise the settings method's new optional parameter.
- `APP_ENV=test ALLOW_ANONYMOUS_WEB=1 PYTHONPATH=backend python -c 'import webapp.app; import main'`: passed.
- `python tools/check_openhands_control_plane.py` and `python -m unittest tools.test_openhands_control_plane -q`: passed (five policy tests).
- Broader repository `ruff check .` reports 270 findings in unchanged code; advisory `mypy --ignore-missing-imports backend` reports 35 errors across 18 unchanged files. These are not frontend regressions and are not suppressed by this change.

The required frontend CI job now runs the accessibility contract and Playwright journeys as well as its existing build and unit tests.

## Boundaries

Collection pagination is over the existing authenticated API response, not server pagination; it reduces rendered content without claiming to reduce API payload size. No backend records, provider credentials, programme prescriptions, authentication rules or tenant filters change. Server-provided charts keep the existing rendering contract. Live OAuth, notification delivery, provider sync and production deployment were not exercised by the mocked browser suite. User-selected timezone support remains tracked separately in #1037.
