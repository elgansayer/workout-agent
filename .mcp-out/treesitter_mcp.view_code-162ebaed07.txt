   3 | Health Connect data is locked to the Android device for privacy. The intended
   4 | flow is to use an app such as Health Sync or Tasker to drop a small daily JSON
   5 | file into a folder synced to this machine. This module reads that file if it
   6 | exists. If it is missing or malformed, the agent simply runs without recovery
