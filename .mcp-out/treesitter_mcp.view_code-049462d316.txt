   1 | """Global authentication boundary for the Workout Agent web application.
   2 | 
   3 | Personalised routes fail closed by default.  The only anonymous HTTP surface is
   4 | an explicit set of login/OAuth/health routes plus narrowly recognised static
   5 | assets needed to render the login shell.  The boundary is installed at the
   6 | FastAPI middleware-stack level so future HTML, JSON, streaming, download, or
   7 | diagnostic routes inherit authentication without route-by-route opt-in.
   8 | 
   9 | A signed session cookie only proves who logged in earlier.  In authenticated
  10 | mode every request is therefore also re-checked against the account's current
  11 | server-side state (allowlist, suspension, deletion, revoked sessions) through a
  12 | mandatory *session guard*.  A session the guard refuses is cleared and answered
  13 | exactly like a request that never had a session, so the response cannot be used
  14 | to learn why access ended.
  15 | """
